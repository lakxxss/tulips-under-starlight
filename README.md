# Tulips Under Starlight

A hand-tied ASCII bouquet of crystal-white tulips beneath a softly sparkling night sky.

## View it

Open [`index.html`](index.html) in a browser, or enable GitHub Pages for this repository to publish it as a website.

## Run the terminal version

With Python 3 installed, run:

```powershell
python tulips-in-starlight.py
```

The terminal animation uses only Python's standard library. Press **Ctrl+C** to exit.
